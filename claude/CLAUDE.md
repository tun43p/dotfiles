# CLAUDE.md

## Important Rules

- Be extremely concise. Sacrifice grammar for the sake of concision.
- All code and documentation must be written in English. Never use a language other than English.

## Git Conventions

If you need to commit something, you must always follow these rules and never deviate from them:

- All commits must be signed; if they aren't, there's a problem.
- The `init: initial commit` must **ALWAYS** be the first commit for new projects, and it must ONLY and ALWAYS consist of a README.md and a LICENSE file.
- All commits must **ALWAYS** be conventional commits and as detailed as possible, be atomic and self-contained.
- Commit messages must NEVER be in any language other than English.
- NEVER add `Co-authored-by: Claude <claude@anthropic.com>` to any commit or Pull Request or any other form of authorship.
- - Example: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` is prohibited.
